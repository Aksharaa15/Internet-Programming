About this page

Every page starts with a <!DOCTYPE html> declaration, a lang attribute and a viewport tag. Inside the body, semantic elements such as <header>, <nav>, <main> and <footer> tell browsers and assistive tools what each part is for.

The CSS begins with a small reset so spacing and sizing behave the same in Chrome, Firefox, Safari and Edge. Layout uses flexbox and relative units, so the page adapts from a phone to a wide desktop screen.
